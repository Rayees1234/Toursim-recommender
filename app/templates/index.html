Academic Submission & Technical Documentation

1. System Architecture

End-to-end pipeline: Raw JSON datasets (immutable in data/raw/) → Data Cleaning & Standardization → Star Schema Warehouse (MySQL 8.0 with SQLite fallback) → OLAP Query Engine → Data Mining (K-Means, FP-Growth, Zero-Leakage Classification, Isolation Forest, Trend Analysis) → Flask REST API → Dynamic Interactive Dashboard.

2. Star Schema & Grain Specification

Fact Grain: One row per tourist destination observation snapshot (100 rows). Measures include stay duration, physical altitude, transport distances, evaluative ratings, and itemized daily expenditures across Budget, Mid-range, and Luxury tiers. Multi-valued dimensions (trip types, activities, lodging, seasons) are modeled via 1NF bridge tables.

3. Data Mining Highlights

  • K-Means: Evaluated for k ∈ [2, 6] using Silhouette & Elbow analysis. Cluster names are programmatically generated from centroid coordinates.
  • Association Rules: Frequent itemsets mined via FP-Growth on multi-valued bridges, filtering trivial rules (Lift > 1.0) and translating to English sentences.
  • Classification: Compares Random Forest (90.0% accuracy), Logistic Regression, and Decision Trees under a strict Zero-Leakage policy.
  • Outlier Detection: Combines univariate IQR thresholds with multivariate Isolation Forest to identify anomalous travel profiles.
